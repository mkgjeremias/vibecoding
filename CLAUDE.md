# Instructions du projet — Tournées commerciales

## Règles

1. **Appuie-toi sur [SPEC.md](tournees-commerciales/SPEC.md) pour toutes tes décisions.** En cas de doute ou de demande hors périmètre, signale-le avant d'agir.
2. **Uniquement HTML, CSS et JavaScript**, sans framework, sans build et sans rien installer (Node.js n'est pas disponible sur ce poste). Seule bibliothèque : Leaflet, copiée dans `vendor/`. Pas de nouvelle bibliothèque sans accord explicite.
3. **À chaque demande**, ajoute le prompt reçu à la fin de [PROMPTS.md](PROMPTS.md), précédé de la date (format `AAAA-MM-JJ`).
4. **Vérifie avec les tests** : `tests.html` (calculs) et `tests-ui.html` (interface), ouverts dans Chrome en mode headless.
